## [▶ Live Demo](https://madb0i.github.io/gracias-messi/)

Open it on mobile or PC — no install, no server. The whole site is one HTML
file plus small dependency-free JS modules.

**The page itself:**
- Handwritten "Gracias, Argentina" that writes itself in, stroke by stroke
- Animated stat counters (927 goals, 460 assists, 47 trophies, 8 Ballons d'Or)
- 22-season goals chart with hover tooltips + a contributions-style heatmap
- Downloadable PNG stat cards (click to save)
- 3D parallax gallery of the places and objects — credited, real photos
- 5-chapter deep-dive bio (~1,700 words) that **turns pages** like a notebook
- Trophy case, career timeline, and a margin doodle of the 10, sketched in

**Interactive systems:**
- **Wall of Gracias** — a crowd-sourced guestbook. No server: each note is a
  GitHub issue in this repo, read back through the public GitHub API.
- **Where Were You** — type your birth year and the timeline rewrites to show
  your age at every milestone (or "Not born yet").
- **Generate my recap** — a ~15-second vertical video of the stats, trophies,
  and timeline, drawn on a canvas and recorded in your browser. Nothing uploads.
- **Crowd ambience** — an opt-in, fully *synthesized* stadium swell (Web Audio,
  no samples) that rises as you scroll past the big moments.
- **EN / ES / HI** — toggle the language; prose translates, numbers stay.
- Plus: ink scroll progress, chapter dot-nav, a `/` command palette, and a
  GOAT easter egg (type it).
