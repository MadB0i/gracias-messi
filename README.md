**[Live Demo →](https://madb0i.github.io/gracias-messi/)** — open on mobile or PC, no install needed.

Open `messi-tribute.html` in any browser. No server needed.

**What's inside:**
- Animated stat counters (927 goals, 460 assists, 47 trophies, 8 Ballons d'Or)
- 22-season goals chart with hover tooltips
- Downloadable PNG stat cards (click to save)
- 3D parallax image gallery
- 5-chapter deep-dive bio (~1,700 words)
- Trophy case grouped by club
- Career timeline with milestones

**Also includes:**
- [`messi-career.json`](messi-career.json) — all verified stats as reusable JSON
- [`widget.html`](widget.html) — embeddable mini tribute (200px)

```html
<!-- embed on any site -->
<iframe src="widget.html" width="100%" height="200" style="border:none" loading="lazy"></iframe>
```
